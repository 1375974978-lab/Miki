# 体线簿视觉方向

## 核心方向

「运动封面 × 柔和运动手帐」。

页面首先像一张有力量的训练封面，进入细节后逐渐显出个人记录册的温度。数据清楚、操作直接，但视觉上保留纸张、贴纸、手写批注和轻微不规则的触感。

## 参考拆解

- Refero Styles 的 Craft Docs：借鉴数字剪贴簿的纸张层次、柔和色块和宽松留白；不照搬其品牌配色。
- Kage 的 Minimal / Playful 案例：借鉴单一视觉焦点、大字号标题和少量高饱和色彩。
- Colorion CSS Text Effects（MIT）：借鉴一次性文字揭示与高亮扫过；只用于页面标题和保存完成反馈。
- Minimal Gallery：借鉴克制的信息层级与留白。
- Awwwards 收录的 Vibrant Wellness 3D body interaction：借鉴连续空间、聚焦式镜头和内容侧滑，不复制其视觉资产。
- unDraw：保留现有可商用矢量人物插画。

## 字体系统

- 标题、部位名、动作名、关键数字：Smiley Sans / 得意黑。
- 操作按钮、正文、表单、辅助说明：PingFang SC，其他设备回退到思源黑体或 Microsoft YaHei。
- 日期、打卡文案、手帐注释：Kaiti SC，其他设备回退到霞鹜文楷。

## 页面规则

- 竖屏 App 宽度优先，桌面端保持 430px 手机画布。
- 首页以 CC0 女性 3D 人体为唯一主视觉；可拖动旋转，也可直接点击人体部位。
- 点击部位后，身体知识从底部滑入；从顶部任意位置下滑可以收起。点击“进入训练”后，动作页面在同一抽屉内横向滑入。
- 动作完成后返回首页，不重新加载页面，也不打断 3D 画布状态。
- 训练清单由打印机槽口缓慢吐出，纸张逐行显影；清单与打印机顶部均可下滑收起。每一组为独立勾选单元，完成单个动作与整次训练时分别提供礼花反馈。
- 纸张纹理和虚线只用于分区，不堆叠装饰。
- 页面进入时的高亮扫过只播放一次，并适配 `prefers-reduced-motion`。
