# 素材来源与许可

本项目只使用可免费商用的开源图标与矢量插画，并将其保存为本地文件。网页运行时不需要从素材 CDN 加载资源。

Lucide ISC 许可允许为任何目的使用、复制、修改和分发该软件，但要求在副本中保留版权与许可声明。完整许可文本见 https://lucide.dev/license 。

## 3D 与交互库

- **Woman Base Mesh**：https://grab3d.com/models/characters/woman-base-character/ ，CC0 1.0 公共领域，可免费用于个人与商业项目且无需署名。项目使用 Light 版本 `assets/models/woman-base-light.glb`，并提供同内容的 Base64 版本 `assets/models/woman-base-light.glb.js` 以便 `file://` 直接打开。
- **Three.js 0.128.0**：https://threejs.org/ ，MIT License。使用文件位于 `assets/vendor/three.min.js` 与 `assets/vendor/GLTFLoader.js`。
- **canvas-confetti 1.9.3**：https://github.com/catdad/canvas-confetti ，ISC License。使用文件位于 `assets/vendor/confetti.browser.js`。

Grab3D 的许可文件注明，该人体模型为 AI-assisted asset（AI 辅助生成后经 Blender 清理和纹理处理），但资产本身以 CC0 1.0 发布，允许个人与商业使用。
