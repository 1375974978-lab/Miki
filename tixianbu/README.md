# 体线簿

轻量化塑形训练记录工具，支持按训练部位选择动作打卡，附带动作教学视频入口，自动估算训练热量；定期录入身材指标，生成可视化变化曲线。关注女性居家塑形的「学习动作-训练打卡-长期体态复盘」完整闭环，捕捉健身人群记录力量进步、追踪体态变化的使用需求。

## 线上地址

- 访问地址：[https://tixianbu.netlify.app](https://tixianbu.netlify.app)
- 托管平台：Netlify Free

## 本地运行

直接双击 `index.html` 即可使用。网站不需要后端或打包步骤，Three.js、字体、图标和人体模型都已放在项目本地；训练记录、收藏、身材数据和里程碑保存在当前浏览器的 LocalStorage 中。

也可以在当前目录启动一个本地静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 功能

- 臀腿、背部、肩部、胸部、核心、有氧六类、共 75 个训练动作。
- 每个部位支持按徒手、哑铃、弹力带、杠铃、固定器械、有氧器械或跳绳多选筛选，并优先推荐当前可用动作；收藏动作始终靠前。
- 竖屏单空间交互：3D 人体始终留在背景中，部位知识、器械筛选和动作清单通过底部抽屉连续滑入；从抽屉顶部下滑即可收起。
- 首页提供可 360° 拖动的女性 3D 人体，点击身体区域会聚焦部位并显示对应训练知识。
- 力量动作记录带 `kg` 单位的重量、组数、每组次数；有氧动作记录训练分钟数。
- 按动作强度、训练量、身体重量估算热量，并生成可复制的打卡文案。
- 选择动作后，训练清单会从打印机中缓缓吐出；每一组单独勾选，单个动作完成时触发轻量礼花。
- 清单支持继续添加其他部位动作；全部组数完成后，训练结算会继续打印在清单顶部。
- 训练、身材、日历三个一级入口并列；日历显示训练部位，点击日期可回看当天完整训练小票。
- 记录体重、体脂率、腰围、臀围，切换四种指标查看响应式趋势曲线。
- 在趋势图上手动添加训练里程碑。
- 身材历史记录按日期回看，可更新同日期记录或删除错误记录。
- 手机宽度优先；桌面端以 430px 竖向应用画布呈现，不铺满浏览器。
- 支持键盘操作、浏览器前进后退和减少动态效果的系统偏好。

## 视觉方向

当前采用「运动封面 × 柔和运动手帐」方向：得意黑承担页面标题、动作名与高对比数字，苹方承担正文和全部表单操作，楷体用于日期与打卡批注。深墨绿训练封面、雾绿纸张、浅色部位贴纸、虚线分隔和方格纸图表共同构成记录册体验；页面进入时仅保留下划线扫过与内容切换两种动效。

## 本地数据说明

数据键名为 `tixianbu:data:v1`。清除浏览器缓存或站点数据会清空全部记录。教学视频按钮会跳转至哔哩哔哩搜索结果，除此之外网站运行不需要网络连接。

图标来自 Lucide Icons，插画来自 unDraw；许可与来源记录见 [ASSET_LICENSES.md](ASSET_LICENSES.md)。
